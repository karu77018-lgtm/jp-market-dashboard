# jp-market-dashboard

日本株（東証内国株）の自分用ダッシュボード。売買の推奨ではありません。

- 計算はすべてローカルで実行し、成果物（`index.html` と `data.json`）だけをコミットします。GitHub Actions は使いません。
- データ：JPX上場銘柄一覧＋日足（引け後に更新）。
- `tools/fetch.py`：銘柄一覧と日足の取得（ローカル実行）
- `tools/build.py`：地合い・広がり・33業種・トレンドテンプレート・RS・スイング候補の計算 → `data.json`

米国版のルールを移植した初版で、日本株での検証はまだです。
